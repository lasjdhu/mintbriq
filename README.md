# MintBriq [![MIT License](https://img.shields.io/badge/license-MIT-22c55e.svg)](LICENSE)

A content-based recommendation engine for finding your next pet project.

## Motivation

Choosing a project that is both achievable and challenging is difficult.
MintBriq analyzes a developer's public GitHub work to recommend ideas close
enough to their current skills to build, but different enough to learn from.

## Usage

```bash
pnpm install
pnpm dev
```

Open [localhost:3000](http://localhost:3000) and enter a GitHub username.
